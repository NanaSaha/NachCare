# Requirement Traceability

Maps every FR-x / AI-x / NFR-x requirement ID implemented so far to the files
that implement it and the spec files that verify it. Updated in the same
commit as the feature that implements it (CI greps new `FR-`/`AI-`/`NFR-`
mentions in commit messages against this table).

The companion SRS (full FR/AI/NFR requirement text) isn't in this repo — see
`docs/OPEN_CLINICAL_ITEMS.md` #1. IDs below are the ones the build playbook
itself names for each phase; descriptions are inferred from the playbook's
prose, not quoted from the SRS. Re-verify against the SRS once available.
